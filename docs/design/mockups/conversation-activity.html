What the agent touched, one click away

Today a person who wants to see what an agent changed opens the pane, then picks Diff, Browser or Canvas from its tab strip. This mock-up puts a small set of buttons on the right of the chat instead. A button appears the first time the agent edits files, opens a page, draws on a canvas, spawns an agent or produces an image, and clicking it opens the pane on that tab. The set belongs to the conversation, so it is still there after the run. The new Library tab collects every image in the chat. Press Replay the run to watch the set grow, then hover and click.

Recommendation: A, the rail, with B's rows on hover

At rest the rail is one 46px column of glyphs, so it fits a narrow window and never covers the transcript. Hovering opens it out to the same rows as the card: a name, and the facts that tell you whether to click (+142 −18, the page's host, "1 working"). Once the pane is open, the rail doubles as its tab bar: the open tab is the selected row, and one click switches tabs. The card (B) has more to read, but it takes about 280px of the chat's width while it is docked and has to fall back to a popover when the window narrows, as the narrow toggle shows. The chip (C) is the calmest, but every look costs two clicks.

What the rows show

  • Order. Rows appear in the order the agent first touched each thing, so the set reads as a short history of the run. Rows don't reorder later, so a row you have found stays where it is. Library stays last, because it holds what came out of the run rather than a place the agent worked.
  • A row the agent is in right now has its glyph in the agent-trail violet the pane tabs and Files tree already use. A spawned agent's row uses its agent glyph. No dots.
  • New, not yet opened: the glyph is in primary ink instead of muted. Opening the row clears it.
  • One accent at most: the green is only the pane's active-tab underline.

Library

  • Every image in the conversation, newest first: what you attached, the agent's browser and canvas screenshots, and images in its replies.
  • Filter by who added it. Each tile has a "Jump to message" link back into the transcript.
  • A pane tab like the others, so it can be maximised, popped out or kept open next to the chat.

Things to decide

  • A, B or C? Or A plus C's chip in the title bar, for when the rail is hidden?
  • Should the set cover the whole conversation (as drawn) or reset each turn?
  • Should Terminal join the set when the agent runs a long command?
  • Does the floating mini-player stay as it is, or tuck into the Browser row when you close it?
